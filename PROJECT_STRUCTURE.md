# Euro Haul project structure

This repository is the source project. Android build outputs are generated by GitHub Actions and uploaded as the `Euro-Haul-Android-APK` artifact; they are not committed to the repository.

## Runtime content

- `assets/models/`: licensed truck, trailer, traffic-vehicle and cargo models.
- `assets/maps/`: original European road networks, terrain and region data.
- `assets/audio/`: licensed engine, drivetrain, traffic and weather audio.
- `assets/textures/`: optimized PBR materials and texture sets.

The Android workflow currently downloads and stages licensed GLB collections into the generated Godot/Babylon project at build time. The source asset manifest and license register are in `ASSET_SOURCES.md`. Do not add empty or repeated files to inflate package size.

## Gameplay source

- `src/physics/`: vehicle dynamics, braking, grip and suspension.
- `src/vehicles/`: truck setup, engines, gearbox and handling.
- `src/traffic/`: AI vehicle behaviour.
- `src/missions/`: cargo and delivery contracts.
- `src/career/`: progression, economy and company management.
- `src/ui/`: menus, GPS and in-game interfaces.

The currently integrated game implementation remains in `overrides/src/main.js` and `overrides/src/style.css`; the workflow copies these into the generated application. The new module directories document the intended separation and are not yet independent runtime modules. Keep that source of truth intact until each subsystem is extracted, imported and tested.

## Build

`.github/workflows/android-apk.yml` builds, verifies and uploads the Android APK. `build/` is reserved for local/generated build output and should not contain committed APK binaries.
